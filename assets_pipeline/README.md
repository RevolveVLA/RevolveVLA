# Asset pipeline

A one-time step, not a component: `./revolve assets` (= `assets_pipeline/make_assets.sh [--out DIR] [--offline]`)
fetches the kitchen's inputs into `assets/` (git-ignored, repo root) where their licences allow it, then converts
them to Gazebo SDF models next to them. It runs in its own dependency-only image, `revolve-assets`
(`Dockerfile`: Python, numpy, scipy, PyYAML, CoACD, trimesh; built by the script, no GPU, no Gazebo). The
simulator reads the models in place from `assets/` through the repo mount; they are never copied into git or an
image.

Inputs (licence-bound, non-commercial: never commit them):
- PartNet-Mobility 11211 (fridge) + 46452 (cabinet): gated, so not downloaded here. Request access
  ([SAPIEN](https://sapien.ucsd.edu), non-commercial research use) and put each object as
  `assets/partnet_mobility/zips/<id>.zip` (unpacked by the script) or `assets/partnet_mobility/dataset/<id>/`.
- The ReplicaCAD table and cup (8 files, 1.2 MB; CC BY-NC 4.0, credit Meta Habitat 2.0 if the table appears in a
  video): downloaded into `assets/replicacad/` from
  [ai-habitat/ReplicaCAD_dataset](https://huggingface.co/datasets/ai-habitat/ReplicaCAD_dataset) if missing.
- CC0 room textures from [ambientCG](https://ambientcg.com) (pinned ids and sha256 in `make_room.py`), cached in
  `assets/textures/`. `--offline` (or a failed download) gives the room plain colours.

Outputs (`DIR` defaults to `assets/`):
- `DIR/generated_partnet/`: `fridge`, `kitchen_counter` (`urdf_to_gz.py`: URDF -> SDF + CoACD collisions).
- `DIR/generated/`: `table_01`, `replicacad_cup_01`, `cup` (the ReplicaCAD cup if it fits the Panda gripper, else
  the primitive cylinder in `primitives/`), and the room shell `kitchen_room_partnet` (`make_room.py`).

Per-object options are in `configs/` (see the `urdf_to_gz.py` docstring). The "Generated by asset_pipeline/..."
headers written into the models are kept as they were, so regenerated files match the existing ones. The models
are not load-tested here: the simulator's bring-up loads them under the MuJoCo plugin.
